# Как предложить сервис

Пулл-реквесты приветствуются! Правила простые:

1. **Один PR — один сервис.** Так проще ревьюить.
2. Сервис должен быть **живым** и относиться к нейросетям (модель, инструмент, агрегатор).
3. Заполни все колонки таблицы: доступ из РФ, бесплатный тариф, описание одной строкой.
4. Описание — нейтральное и по делу, без маркетинговых превосходных степеней.
5. Если сервис перестал работать из РФ — тоже присылай PR, актуальность важнее полноты.

Спорные случаи обсуждаем в Issues.
